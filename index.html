          📖 Panduan Cara Pakai UI Maker
        

        
      


      

        

          Langkah 1: Setup API Key
          Klik tombol API Key di kanan atas, lalu masukkan Gemini API Key gratis Anda (dapatkan di Google AI Studio). Disimpan aman di browser Anda.
        


        

          Langkah 2: Tempel Chat Klien
          Klien sering kali memberikan instruksi yang acak-acakan di WhatsApp/Email. Cukup salin seluruh percakapan chat tersebut dan tempelkan ke kolom "Daftar Chat Klien".
        


        

          Langkah 3: Jawab Pilihan Ganda Bertingkat
          Klik "Pahami Chat Klien". AI akan membedah kebutuhan bisnis klien dan memberikan beberapa pilihan ganda (gaya desain, susunan section, skema warna). Anda cukup klik pilihan terbaik menurut selera Anda!
        


        

          Langkah 4: Hasil & Export ke GAS
          Website akan langsung tampil di Live Canvas. Klik tombol Export GAS di kanan atas untuk mendapatkan kode Index.html dan Code.gs yang siap dimasukkan ke Google Apps Script!
